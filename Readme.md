# 🎨 Smart Scheduling Using Graphs

### 🚀 A Data Structures & Algorithms (DSA) Based Graph Coloring Planner

A C++ project that demonstrates how **Graph Data Structures and Algorithms** can solve real-world scheduling conflicts.

Using **Greedy Coloring and Backtracking**, the system assigns non-conflicting time slots to classes while ensuring that no two connected vertices receive the same color.

**Built with using C++.**
